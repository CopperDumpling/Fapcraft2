# Fapcraft (26.3)

Ground-up rebuild of the Fapcraft mod for **Minecraft 26.3** on **NeoForge**.
The 1.12.2 source (`../Jenny-Mod-Fapcraft`) is the behavioural reference; see [PLAN.md](PLAN.md).

| | Version |
|---|---|
| Minecraft | 26.3 |
| NeoForge | 26.3.0.86 |
| GeckoLib | 5.5.7 (`com.geckolib:geckolib-neoforge-26.3`) |
| Java | 25 |

```sh
./gradlew build       # jar -> build/libs/
./gradlew runClient   # dev client
```
